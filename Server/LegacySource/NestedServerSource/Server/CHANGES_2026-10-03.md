# Changes

- Added real bug-report handling for the legacy `bugreport` packet, including the original Mapping/Programming/Other and Often/Sometimes/Once labels.
- Bug reports appear in the Bug Reports page and are persisted to `logs/bugs-YYYY-MM-DD.log`.
- Added persistent daily server logs at `logs/server-YYYY-MM-DD.log`.
- Added Log menu actions to open the log folder and clear on-screen lists.
- Fixed startup when SpacetimeDB at `127.0.0.1:3000` is not running. By default the TCP server continues to start and emits a concise warning instead of surfacing the full connection-refused stack trace.
- Added `SpacetimeConnectTimeoutSeconds` and `RequireSpacetimeDb` settings.
- Split UI targets into shared server core + Windows WPF + Linux GTK + macOS projects.
- Added `XtremeWorlds.Server.sln` with Windows / GTK / macOS solution platforms.
- Added `scripts/run-server-platform.ps1` and `scripts/run-server-platform.sh` platform launchers.
- Preserved the TwinBasic-style Windows layout, player right-click administration menu, and Script Editor.
