# Integrated client/server solution

This server is included inside the client repository at `Build/Server`.

Open the repository-root `XtremeWorlds.sln` (or `Client.Windows.sln`) to work on the Windows client, shared Eto UI, engine, VB.NET server, and SpacetimeDB module together.

Server project:
`Build/Server/src/Server/Server.vbproj`

SpacetimeDB module:
`Build/Server/spacetimedb/StdbModule.csproj`
